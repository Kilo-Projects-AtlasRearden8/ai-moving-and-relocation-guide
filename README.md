# AI Moving and Relocation Guide

A beginner-friendly manual on using AI for moving and relocation: packing checklists, address-change timelines, utility transfers, budget tracking, and room-by-room inventory. Includes a printable moving planner you can print and fill in by hand.

Written plain English, step by step, like a friend would explain it. No condescension, no jargon without a definition, and privacy first — we never ask you to enter personal IDs or financial details.

## Who this is for

Anyone moving to a new home who wants a little help from AI. You do not need to be technical. If you can open a website or type a sentence into a chat box, you can use this guide.

It is especially written for people who want a calm, step-by-step plan without the overwhelm — one small task at a time.

## How to read it

Start with [`docs/privacy.md`](docs/privacy.md), then pick a topic that feels most useful right now. There is no wrong order.

The HTML site in `site/` works the same way — open `site/index.html` in your browser and click around. Every page links back to the others.

## Print the planner

The printable planner is designed to print and fill in by hand:

- Open [`site/printable-moving-planner.html`](site/printable-moving-planner.html) in any browser.
- Press `Ctrl+P` (or `Cmd+P`).
- In the print dialog, turn off headers/footers and set margins to None or Minimum.
- Fill in pencil so you can change things as your plan shifts.

Nothing in the planner asks for secrets — leave out account numbers, credit card numbers, and IDs. Keep your filled-in planner somewhere safe.

## Privacy promise

This guide is privacy-first and local-first where possible. We prefer tools that run on your own computer, and we never ask you to enter personal data, API keys, or secrets anywhere in these files.

**The golden rule:** Never scan or upload sensitive IDs (passports, driver's licenses, Social Security cards, birth certificates) or financial documents (bank statements, credit card statements, tax returns) to an AI. If you wouldn't show it to a stranger in line at the grocery store, don't paste it into an AI chat.

Nothing here should go into an AI chat unless you are comfortable with that provider seeing it.
