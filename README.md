# AI Moving and Relocation Guide

A beginner-friendly manual on using AI for moving and relocation: packing checklists, address-change timelines, utility transfers, budget tracking, and room-by-room inventory. Includes a printable moving planner you can print and fill in by hand.

Written plain English, step by step, like a friend would explain it. No condescension, no jargon without a definition, and privacy first — we never ask you to enter personal IDs or financial details.

## Who this is for

Anyone moving to a new home who wants a little help from AI. You do not need to be technical. If you can open a website or type a sentence into a chat box, you can use this guide.

## What's inside

- [`docs/`](docs/) — beginner manuals in Markdown
- [`site/`](site/) — the same manuals as a static HTML website you can open in any browser, print, or host anywhere
- Privacy-first guidance throughout, including the golden rule on nearly every page: **never scan or upload sensitive IDs or financial details to an AI**

## How to read it

Start with [`docs/privacy.md`](docs/privacy.md), then pick a topic: packing, address change, utilities, budget, inventory, or the printable planner. The HTML site in `site/` works the same way — open `site/index.html` in your browser.

## Privacy promise

This guide is privacy-first and local-first where possible. We prefer tools that run on your own computer, and we never ask you to enter personal data, API keys, or secrets anywhere in these files. Nothing here should go into an AI chat unless you are comfortable with that provider seeing it.
