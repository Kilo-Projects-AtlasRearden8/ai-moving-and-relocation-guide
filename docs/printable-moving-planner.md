# Printable Moving Planner

This is a printable planner. Print these pages and fill them in by hand. Nothing here asks for secrets — leave out account numbers, credit card numbers, and IDs. Keep your filled-in planner somewhere safe.

Print tips:

- Print on regular paper or cardstock
- In the print dialog, turn off headers/footers and set margins to Minimum
- Fill in pencil so you can change things

## Page 1 — Moving timeline checklist

Check each item when it's done. Dates are yours to fill in.

### 8 weeks before

- [ ] Sort one room: keep / donate / sell / recycle / trash
- [ ] Start using up freezer and pantry food
- [ ] Research movers or truck rental
- [ ] Begin room-by-room inventory

### 6 weeks before

- [ ] Pack off-season clothes, books, decorations
- [ ] Label every box (room + contents)
- [ ] Start address-change list
- [ ] Gather utility info (account numbers stay on paper with you)

### 4 weeks before

- [ ] Confirm movers or truck reservation
- [ ] Pack rarely used rooms (guest room, attic, basement)
- [ ] Schedule utility shut-off and turn-on
- [ ] Request moving-day time off work

### 2 weeks before

- [ ] Finish packing non-essentials
- [ ] Pack essentials box (keep it with you)
- [ ] File change of address with the post office
- [ ] Defrost and clean fridge/freezer

### 1 week before

- [ ] Pack daily essentials last
- [ ] Confirm moving-day details
- [ ] Pack a suitcase per person (3-night trip)
- [ ] Final walk-through of each room

### Moving day

- [ ] Final sweep of every room, closet, drawer
- [ ] Take meter readings (electric, gas, water)
- [ ] Lock windows and doors; leave keys as agreed
- [ ] Walk through new place before unloading

### After you move

- [ ] Unpack essentials box first
- [ ] Set up beds and basic kitchen items
- [ ] Finish address changes where still needed
- [ ] Update driver's license and voter registration if new state

## Page 2 — Essentials box (carry with you, not in the truck)

- [ ] Snacks and water
- [ ] Change of clothes and pajamas
- [ ] Pet food and supplies (if you have pets)
- [ ] One pot, one pan, plates, cups, utensils

## Tips for a smoother move

- Pack one room per day. Small steps beat big rushes.
- Label every box on two sides so you can read it when stacked.
- Keep this planner with you on moving day.
- Ask AI to rewrite any checklist in this planner to fit your home — just don't paste in account numbers or IDs.
